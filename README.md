# 매일 한자 (daily Hanja)

> 매일 5분 한자를 알면 어휘가 보인다

평일(월~금) 아침 **5분**, 하루에 **한자 한 자**씩 **뜻(훈)과 음**을 익히는 웹 앱입니다.
글자 모양을 외우는 대신, 초등학교 교과서에 자주 나오는 **활용 어휘 4개** 속에서 한자의 음훈을 익히고, **음훈으로 어휘의 뜻을 짐작하는 힘**을 기릅니다.

## 실행 방법

설치나 빌드 과정이 없는 정적 웹 앱입니다.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 열기
```

GitHub Pages에 그대로 올려도 동작합니다.

## 입장과 학생별 기록

- **처음 왔어요**에서 이름(아이디)과 비밀번호(4글자 이상)를 만들고, 다음부터는 **입장하기**로 들어옵니다. 다 쓰면 화면 위 이름 옆의 **로그아웃**을 누릅니다.
- 배운 한자, 레벨테스트·급수 시험 결과, 퀴즈, 글짓기 기록이 **학생별로 따로 쌓입니다.**
- 기록은 **Firebase(Firestore)에 저장**되어 다른 기기에서도 이름과 비밀번호로 입장하면 이어서 공부할 수 있습니다. 인터넷이 끊기면 그 기기에 먼저 저장해 두었다가, 다시 연결되면 더 나중에 고친 기록으로 맞춥니다. 오래 켜 둔 기기의 옛 화면이 다른 기기에서 공부한 새 기록을 덮어쓰지 않도록, 그 사이 서버 기록이 바뀌었으면 저장하지 않고 새 기록을 불러옵니다(켜 둔 화면도 1분마다 새 기록을 확인해요).
- **선생님 메뉴**(입장 화면 아래 또는 설정): 처음 한 번 선생님 비밀번호를 정하면, 학생별 진도(급수·단계, 아는 한자, 공부한 한자, 급수 시험 점수, 최근 글짓기)를 보고 **학생 비밀번호를 초기화**하거나 학생을 삭제할 수 있습니다.
- 비밀번호는 친구가 내 기록에 들어오지 못하게 막는 정도의 간단한 보호입니다. (Firebase 로그인 기능은 쓰지 않습니다.)

### Firebase 설정

`js/cloud.js`의 `firebaseConfig`에 프로젝트 설정값이 들어 있습니다. Firestore 보안 규칙은 아래처럼 둡니다.

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /students/{id} { allow read, write: if true; }
    match /meta/{id} { allow read, write: if true; }
  }
}
```

- `students/{이름}`: 학생마다 한 문서 (비밀번호 해시, 학습 기록, 마지막으로 고친 시각)
- `meta/teacher`: 선생님 비밀번호 해시

## 개별 맞춤 학습 (완전 학습)

```
레벨테스트(급수 전체) ──모두 맞힘──────────────────────────────┐
      │ 틀린 한자 있음                                           ▼
      ▼                                                  다음 급수 레벨테스트
틀린 한자만 평일 하루 1자씩 학습 (원하면 '한 자 더 배우기')          ▲
      │ 모두 배움                                                │
      ▼                                                          │
급수 시험(급수 전체) ──100점─────────────────────────────────────┘
      │ 100점이 아니면
      ▼
틀린 한자 짧게 다시 보기(오늘의 한자 + 뜻 연결 + 확인하기) → 급수 시험 다시
```

- **레벨테스트**: 8급부터 시작합니다. 왼쪽의 한자 1자와 오른쪽의 한글 활용 어휘 2개(예: 校 — 학**교** · **교**문, 그 한자의 음은 빨간색)를 보고 **뜻과 음을 직접 씁니다**. 모르는 한자는 '몰라요'로 빠르게 넘기고, 시험 중에는 '← 이전' 버튼으로 앞의 답을 고칠 수 있습니다. 맞힌 한자는 '이미 아는 한자'가 되어 다시 공부하지 않습니다.
- **완전 학습**: 학습 중 **4 확인하기** 또는 **5 추론하기**를 틀리면 그 한자는 **다음 학습일의 '오늘의 한자'로 1~6단계를 다시** 배웁니다. 모든 한자를 틀림없이 마쳐야 급수 시험에 도전할 수 있습니다.
- **급수 시험**: 레벨테스트와 같은 모양으로 **급수 전체 한자**를 봅니다. **100점**이어야 다음 급수로 올라갑니다.
- 음은 맞고 뜻을 다르게 쓴 답은 **선생님만 인정**할 수 있습니다. 결과 화면에서 선생님 비밀번호를 넣고 바로 인정하거나, 확인하지 못한 답은 선생님 메뉴의 학생 상세 화면('선생님 확인을 기다리는 답')에서 나중에 인정합니다. 인정하면 레벨테스트는 그 한자가 '이미 아는 한자'가 되고, 급수 시험은 점수에 반영되어 100점이 되면 다음 급수로 올라갑니다.

## 하루 학습 흐름 (약 5분)

| 요일 | 내용 |
| --- | --- |
| (입장) | 🔁 **입장 복습**: 그날 처음 앱을 열거나 입장하면 바로 ① **지난 급수 복습**(아래 급수에서 앱으로 공부한 한자 3자를 한글 어휘로 뜻·음 쓰기, 숫자 한자 一~十은 빼고 틀렸던 한자·오래전에 본 한자 먼저)과 ② **어제 배운 한자 복습**(평일, 지난 학습일의 한자 + 틀렸던 한자 최대 2자)을 해요. 복습할 한자가 없으면 건너뛰고, 하루 한 번만 나와요 |
| 월~목 | (어제 배운 한자 복습은 입장할 때 해요)<br>**1. 오늘의 한자**: 뜻(훈)과 소리(음)<br>**2. 활용 어휘 ①**: 왼쪽 어휘(한자 + 글자별 음훈, 음은 굵게)와 오른쪽 뜻을 **선으로 연결**<br>**3. 활용 어휘 ②**: 위의 보기(활용 어휘 4개)에서 골라 문장 4개의 빈칸 채우기<br>**4. 확인하기**: 한글 어휘(예: 학**교**)에서 표시된 글자에 쓰인 한자의 뜻과 음 쓰기 → 바로 채점, 틀리면 까닭과 해설<br>**5. 추론하기**: 활용 어휘에 없던 처음 보는 어휘 2개(한글) 가운데 오늘의 한자가 **쓰인** 것 고르기(다른 하나는 소리는 같지만 뜻이 다른 한자의 어휘) → 바로 채점, 맞아도 틀려도 해설(두 보기를 나란히 놓고 오늘 한자의 음훈은 초록, 소리만 같은 한자·우리말은 빨강)<br>**6. 적용하기**: 배운 낱말을 넣어 짧은 글짓기(저장됨) |
| 금 | 위 과정 + ⭐ **일주일 복습**: 이번 주 한자 5자 퀴즈와 정리표 |
| (홈) | 학습을 마치면 오늘 새로 배운 한자(한 자 더 배우기 포함)를 카드로 **다시 보기**, 옆으로 밀거나 ‹ › 버튼으로 넘겨 봅니다 |
| 토·일 | 쉬는 날. 금요일에 일주일 복습을 놓쳤다면 주말에 할 수 있고, 자유 복습(5문제)도 할 수 있어요 |

- **에빙하우스 망각 곡선**에 맞춰 잊어버리기 직전에 다시 떠올리도록 **1일 후 → 금요일(주간) → 급수 시험**으로 복습합니다.
- 퀴즈나 시험에서 틀린 한자는 '다시 볼 한자'에 모여 다음 복습에 다시 나옵니다.
- 하루를 빠뜨려도 진도는 밀리지 않고 다음 학습일에 이어서 배웁니다.

## 학습 시간과 합격증

- 공부 화면(입장 복습, 오늘의 학습, 한 자 더 배우기, 복습, 레벨테스트, 급수 시험)을 **실제로 보고 있는 시간만** 셉니다. 다른 창으로 가거나 화면이 꺼졌을 때, 2분 동안 아무 입력이 없을 때는 세지 않아요.
- 공부 화면 오른쪽 위에 오늘 공부한 시간(⏱)이 흐르고, 그날 **5분을 넘기는 순간** 우리말 격려가 잠깐 떠요. 끝 화면에도 오늘 공부한 시간과 격려가 나와요.
- 📒 학습 기록: 오늘·모두 합친 시간, 날짜별 시간
- 👩‍🏫 선생님 메뉴: 학생별 오늘·총 시간, 이름을 누르면 최근 2주 날짜별 시간. 통과한 급수 옆 **🖨 합격증**을 누르면 A4 합격증(이름, 급수, 합격 날짜, 그때까지의 총 학습 시간)이 새 창에 열리고 바로 인쇄 창이 떠요. 학교 이름·선생님 이름은 선생님 메뉴에서 정하면 들어가요(그 기기에 저장).

## 채점

- 음은 두음 법칙(력→역, 녀→여 등)을 인정합니다.
- 뜻은 기본형(배울 → 배우다, 곧을 → 곧다)도 인정합니다.

## 수록 한자

한국어문회 한자능력검정시험 배정 한자 기준입니다.

| 급수 | 새로 배우는 한자 | 상태 |
| --- | --- | --- |
| 8급 | 50자 | ✅ 수록 |
| 7급Ⅱ | 50자 | ✅ 수록 |
| 7급 | 50자 | ✅ 수록 |
| 6급Ⅱ | 75자 | ✅ 수록 |
| 6급 | 75자 | ✅ 수록 |
| 5급Ⅱ ~ 1급 | — | 준비 중 |

지금은 모두 300자로, 평일에 한 자씩 배우면 약 60주 분량입니다. 한자마다 활용 어휘 4개와 빈칸 채우기 문장 4개가 들어 있습니다.

### 한자 추가하기

`js/data.js`의 `GRADES` 배열에 같은 형식으로 급수를 이어 붙이면 앱 전체(학습, 목록, 시험)에 자동으로 반영됩니다.
어휘에 학습 한자가 아닌 글자가 들어가면 `js/hunum.js`에 그 글자의 음훈을, `js/sentences.js`에 어휘마다 빈칸 채우기 문장을 추가해 주세요.

```js
['學', '배울', '학', '學校,학교,공부하는 곳;學生,학생,배우는 사람;數學,수학,수와 셈을 배우는 과목;入學,입학,학교에 들어감', '동생이 초등학교에 입학(入學)했어요.'],
```

## 파일 구성

```
index.html      앱 화면 틀
css/style.css   디자인 (라이트/다크 모드)
js/cloud.js     Firebase(Firestore)와 기록 맞추기
js/data.js      한자 데이터 (학습 한자 300자)
js/hunum.js     활용 어휘에 나오는 그 밖의 한자 271자의 음훈
js/sentences.js 활용 어휘 ② 빈칸 채우기 문장 (한자마다 4개, 모두 1,200개)
js/infer.js     5단계 추론하기 어휘 (한자마다 활용 어휘에 없는 새 어휘 1개)
js/app.js       입장(비밀번호), 레벨테스트, 학습 일정, 활동, 급수 시험, 선생님 메뉴, 학생별 저장
```

테스트할 때는 주소 뒤에 `?date=2026-10-02`처럼 날짜를 붙이면 그 날짜(예: 금요일)의 화면을 미리 볼 수 있습니다.
